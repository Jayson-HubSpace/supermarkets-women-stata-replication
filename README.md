# Stata replication code

## Paper

**Supermarkets benefit women by reducing time spent on unpaid housework without lowering nutritional quality**

This repository is intended to host the Stata code and supporting replication materials for the main results reported in the main text of this paper.

## Availability

The replication materials are being prepared and will be added to this repository. No Stata code, datasets, or replication results have been uploaded yet.
